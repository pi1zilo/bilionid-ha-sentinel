# Безопасность

- Команды и кнопки доступны владельцу из `TELEGRAM_ADMIN_USER_ID`. Для ограничения по чату используйте `TELEGRAM_COMMAND_CHAT_ID`.
- Служебный порт по умолчанию привязан к loopback. Для Tailscale задайте приватный `HA_BIND_IP` и ограничьте доступ нужными узлами.
- Служебные запросы используют `X-HA-Secret`. Входящие события используют отдельные `X-Monitor-Secret`. Настройте разные случайные секреты от 32 символов.
- Храните `.env` и бэкапы в закрытом каталоге. Установщик защищает их правами файлов, код маскирует известные секреты в логах.
- Контейнер работает под непривилегированным UID, без дополнительных capabilities и прямого монтирования Docker-сокета. Для Docker используйте фильтрующий прокси.
- Для Beszel и Zabbix используйте отдельные учётные записи с доступом к чтению. Для Kuma создайте ключ Prometheus.
